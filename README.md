# ptaf_backuper
Скрипт для автоматического создания бэкапов по расписанию, а так же их ротации согласно заданному времени жизни бэкапов(backup_ttl)

- **`backup_schedule`** – (опционально) точное расписание в формате systemd calendar.
  Примеры:
  - `"daily 04:30:00"` – каждый день в 4:30 утра
  - `"*-*-* 02:00:00"` – каждый день в 2:00
  - `"Mon..Fri 09:00:00"` – по будням в 9:00
  - `"Sun 03:00:00"` – каждое воскресенье в 3:00
